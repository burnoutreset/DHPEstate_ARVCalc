How to download the right CSVs (first time setup)
1. Redfin (most important): Open Redfin Data Center Downloads. Scroll to find "Region Type: Zip Code" downloads. Get the monthly CSV with sales, DOM, sale-to-list, inventory. File will be named something like zip_code_market_tracker.tsv000.gz or similar. Drop it in zone 1.
2. Zillow ZHVI (home values, for appreciation): Open Zillow Research Data. Under "Home Values", set Geography to ZIP Code, Data Type to ZHVI All Homes Time Series, Smoothed, Seasonally Adjusted. Click Download. Drop in zone 2.
3. Zillow Inventory (optional, for months-of-supply): Same page, under "For-Sale Listings", set Geography to ZIP Code, Data Type to For-Sale Inventory (Smooth, All Homes, Monthly). Click Download. Drop in zone 3.
Refresh cadence: Redfin updates weekly. Zillow updates monthly on the 16th. Re-download and re-drop quarterly is plenty.
